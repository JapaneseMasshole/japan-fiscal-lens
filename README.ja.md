# Japan Fiscal Lens（財政レンズ）

**国と地方自治体の財政を、公式データからグラフで分かりやすく。貸借対照表・行政コスト・資金収支まで。**

[English README](README.md)

日本の財政に関する報道は、「借金1,000兆円超」「税収過去最高」など、ひとつの数字を切り取って語られがちです。Japan Fiscal Lens は、政府自身が公表している数字だけを使って全体像をそのまま示し、誰もが自分の目で見て判断できるようにすることを目指しています。

## 掲載する内容

| 区分 | 内容 | 公式データ |
|---|---|---|
| 国 | 貸借対照表・業務費用計算書・区分別収支計算書 | 財務省「国の財務書類」 |
| 国 | 予算と決算、歳入・歳出の内訳 | 財務省「決算」 |
| 国 | 国債の保有者 | 日本銀行「資金循環統計」 |
| 都道府県・市区町村 | 貸借対照表・行政コスト計算書・資金収支計算書 | 総務省「統一的な基準による財務書類」 |
| 都道府県・市区町村 | 歳入・歳出の内訳、財政指標 | 総務省「決算カード」 |

データの出典はすべて [`data/sources.yaml`](data/sources.yaml) に記載しています。

## 方針

1. **公式データのみを使用。** 独自の推計・予測は行いません。対GDP比などの加工値は、計算方法を [`docs/methodology.md`](docs/methodology.md) に明記します。
2. **すべてのグラフに出典を表示**し、元ファイルへのリンクを付けます。
3. **元データは加工せず保存**（`data/raw/`）。誰でもパイプラインを再実行して同じ数字を再現できます。
4. **見せ方は読者が選ぶ。** 名目／実質、金額／対GDP比、総額／純額を切り替え可能にします。同じデータでも見せ方次第で印象が変わるため、選択は読者に委ねます。
5. **データ更新はプルリクエストで。** 数字の変更履歴はすべて git に残ります。
